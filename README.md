# Air-bnb-data-analysis


End-to-end Airbnb data analysis using Python, Pandas, Matplotlib, and Seaborn. This project cleans, explores, and visualizes Airbnb listings to uncover insights into pricing, room types, neighborhood trends, and customer review patterns.


🏡 Airbnb Data Analysis using Python
📌 Project Overview

This project explores an Airbnb listings dataset to uncover insights into pricing, room types, neighborhood popularity, and customer review trends. The analysis follows a complete data analytics workflow—from data cleaning and preprocessing to exploratory data analysis (EDA) and visualization—using Python.

The objective is to identify patterns that help understand the Airbnb market and support data-driven business decisions for hosts and travelers.

📊 Analysis Performed
Distribution of Airbnb listing prices
Room type availability analysis
Neighborhood-wise listing distribution
Price comparison across room types
Monthly review trends over time
Dataset quality assessment (missing values & duplicates)

🎯 Key Insights
Cleaned and prepared raw Airbnb data for analysis.
Identified pricing patterns across different room types.
Compared listing distribution across neighborhood groups.
Examined review trends to understand customer engagement over time.
Created clear visualizations to communicate business insights effectively.
